# Organization運用方針
このOrganizationはChibaRobotStudioの開発資産を一元管理するためのものです。  
以下の運用方針に従って管理してください。

## リポジトリ管理
### リポジトリの作成
- 原則として、リポジトリは **Private** で作成すること。
- ChibaRobotStudio内の開発資産・設計情報を含むため、公開範囲には注意すること。
### 成果物の管理
- ChibaRobotStudioとして作成した成果物は原則このOrganizationで管理すること。
- ソースコードだけでなく、設計データ（例：KiCadデータ）も対象とする。

理由：
- 個人アカウントに分散すると管理が困難になるため
- 開発資産を一元管理し、引き継ぎ性を高めるため

## 権限管理
### Owner権限
Ownerは以下の者が保持する：
- 制御班長
- サークル長
### Owner権限の引き継ぎ
- 制御班長交代時には、必ずOwner権限の引き継ぎを行うこと。
- 引き継ぎ漏れは運用継続に重大な支障を与えるため、最優先で対応すること。
## 公開・ポートフォリオ利用
- Organization内の成果物を個人ポートフォリオ等に掲載したい場合は、事前に制御班長やサークル長へ相談すること。
- 外部公開による問題がない場合、原則許可する。

ただし以下の場合は要検討：
- 本人が主制作者でない成果物を含む場合
  - 作成者の異なる部内の基盤ライブラリを含む場合など
- その他、継続運用に影響する可能性がある場合
